ESP32-LCDKit
============

:link_to_translation:`en:[English]`

面向小尺寸图形界面和人机交互的 ESP32 开发板。板载能力包括：SPI LCD、触摸、旋钮、音频、红外、WS2812。

板载能力
--------

* SPI LCD、触摸、旋钮、音频、红外、WS2812

硬件用户指南
------------

完整硬件说明见 `ESP32-LCDKit <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32/esp32-lcdkit/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_lcdkit``。
