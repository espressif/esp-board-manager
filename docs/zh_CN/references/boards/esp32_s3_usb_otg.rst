ESP32-S3-USB-OTG
================

:link_to_translation:`en:[English]`

面向 USB 主机和设备应用开发的 ESP32-S3 开发板。板载能力包括：USB OTG、USB Type-C、microSD、按键。

板载能力
--------

* USB OTG、USB Type-C、microSD、按键

硬件用户指南
------------

完整硬件说明见 `ESP32-S3-USB-OTG <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp32-s3-usb-otg/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_s3_usb_otg``。
