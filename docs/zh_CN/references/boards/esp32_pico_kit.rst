ESP32-PICO-KIT v4/v4.1
======================

:link_to_translation:`en:[English]`

基于 ESP32-PICO-D4 的开发板。板载能力包括：ESP32-PICO-D4、USB-UART、GPIO 引脚。

板载能力
--------

* ESP32-PICO-D4、USB-UART、GPIO 引脚

硬件用户指南
------------

完整硬件说明见 `ESP32-PICO-KIT <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32/esp32-pico-kit/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_pico_kit``。
