ESP32-C3-LCDkit
===============

:link_to_translation:`en:[English]`

基于 ESP32-C3 的屏幕应用开发板。板载能力包括：GC9A01 SPI LCD、PDM 扬声器、旋钮、WS2812、SPIFFS。

板载能力
--------

* GC9A01 SPI LCD、PDM 扬声器、旋钮、WS2812、SPIFFS

硬件用户指南
------------

完整硬件说明见 `ESP32-C3-LCDkit <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32c3/esp32-c3-lcdkit/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_c3_lcdkit``。
