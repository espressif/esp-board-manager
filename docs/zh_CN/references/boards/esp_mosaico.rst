ESP-Mosaico V1.0
================

:link_to_translation:`en:[English]`

基于 ESP32-S31 的可扩展智能交互开发套件。板载能力包括：480×480 QSPI 触摸屏、ES8311、BMI270、BMM150、SPI NAND、USB OTG、GPIO Boot 按键。

板载能力
--------

* 480×480 QSPI 触摸屏、ES8311、BMI270、BMM150、SPI NAND、USB OTG、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP-Mosaico <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s31/esp-mosaico/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp_mosaico``。
