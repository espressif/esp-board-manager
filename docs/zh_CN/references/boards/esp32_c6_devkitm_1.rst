ESP32-C6-DevKitM-1
==================

:link_to_translation:`en:[English]`

基于 ESP32-C6-MINI-1 模组的开发板。板载能力包括：ESP32-C6-MINI-1、Wi-Fi 6、802.15.4、USB。

板载能力
--------

* ESP32-C6-MINI-1、Wi-Fi 6、802.15.4、USB

硬件用户指南
------------

完整硬件说明见 `ESP32-C6-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32c6/esp32-c6-devkitm-1/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_c6_devkitm_1``。
