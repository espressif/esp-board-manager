ESP32-S31-Function-CoreBoard-1
==============================

:link_to_translation:`en:[English]`

面向联网 AIoT 原型验证的开发板。板载能力包括：ES8311、麦克风、扬声器接口、WS2812、GPIO Boot 按键。

板载能力
--------

* ES8311、麦克风、扬声器接口、WS2812、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP32-S31-Function-CoreBoard-1 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s31/esp32-s31-function-coreboard-1/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_s31_function_coreboard_1``。该芯片需要 ESP-IDF ``v6.1`` 或更新版本。
