ESP-SensairShuttle v1.0
=======================

:link_to_translation:`en:[English]`

面向动作感知和大模型人机交互的 ESP32-C5 开发板。板载能力包括：BMI270、音频输入输出、LCD、触摸、WS2812、GPIO Boot 按键。

板载能力
--------

* BMI270、音频输入输出、LCD、触摸、WS2812、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP-SensairShuttle <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32c5/esp-sensairshuttle/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp_sensairshuttle``。
