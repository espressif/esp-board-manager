ESP32-MeshKit-Sense
===================

:link_to_translation:`en:[English]`

面向 Wi-Fi Mesh 和环境感知应用的开发套件。板载能力包括：环境传感器、LCD、触摸、Wi-Fi/BLE、GPIO Boot 按键。

板载能力
--------

* 环境传感器、LCD、触摸、Wi-Fi/BLE、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP32-MeshKit-Sense <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32/esp32-meshkit-sensor/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_meshkit_sense``。
