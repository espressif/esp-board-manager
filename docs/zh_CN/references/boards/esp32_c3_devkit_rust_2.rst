ESP32-C3-DevKit-RUST-2
======================

:link_to_translation:`en:[English]`

ESP32-C3 Rust 开发板的改进版本。板载能力包括：ICM-42670-P IMU、SHTC3 温湿度、WS2812、按键、USB。

板载能力
--------

* ICM-42670-P IMU、SHTC3 温湿度、WS2812、按键、USB

硬件用户指南
------------

完整硬件说明见 `ESP32-C3-DevKit-RUST-2 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32c3/esp32-c3-devkit-rust-2/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_c3_devkit_rust_2``。
