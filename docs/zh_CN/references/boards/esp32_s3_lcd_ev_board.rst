ESP32-S3-LCD-EV-Board v1.5
==========================

:link_to_translation:`en:[English]`

用于评估 ESP32-S3 屏幕应用的开发板。板载能力包括：GC9503 RGB LCD、FT5x06、ES8311/ES7210、GPIO Boot 按键。

板载能力
--------

* GC9503 RGB LCD、FT5x06、ES8311/ES7210、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP32-S3-LCD-EV-Board <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp32-s3-lcd-ev-board/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_s3_lcd_ev_board``。
