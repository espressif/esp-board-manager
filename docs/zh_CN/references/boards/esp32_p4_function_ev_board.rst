ESP32-P4-Function-EV-Board v1.5.2
=================================

:link_to_translation:`en:[English]`

基于 ESP32-P4 的多媒体开发板。板载能力包括：DSI 显示、触摸、音频、CSI 摄像头、microSD、GPIO Boot 按键。

板载能力
--------

* DSI 显示、触摸、音频、CSI 摄像头、microSD、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP32-P4-Function-EV-Board <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32p4/esp32-p4-function-ev-board/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_p4_function_ev_board``。
