ESP32-DevKitC V4
================

:link_to_translation:`en:[English]`

基于 ESP32-WROOM-32 的通用开发板。板载能力包括：ESP32-WROOM-32、USB-UART、GPIO 引脚。

板载能力
--------

* ESP32-WROOM-32、USB-UART、GPIO 引脚

硬件用户指南
------------

完整硬件说明见 `ESP32-DevKitC <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32/esp32-devkitc/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_devkitc``。
