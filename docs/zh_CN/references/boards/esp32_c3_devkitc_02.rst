ESP32-C3-DevKitC-02
===================

:link_to_translation:`en:[English]`

基于 ESP32-C3 的通用入门开发板。板载能力包括：ESP32-C3-WROOM-02、USB、GPIO 引脚。

板载能力
--------

* ESP32-C3-WROOM-02、USB、GPIO 引脚

硬件用户指南
------------

完整硬件说明见 `ESP32-C3-DevKitC-02 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32c3/esp32-c3-devkitc-02/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_c3_devkitc_02``。
