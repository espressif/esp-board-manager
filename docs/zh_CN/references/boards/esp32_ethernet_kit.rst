ESP32-Ethernet-Kit v1.2
=======================

:link_to_translation:`en:[English]`

用于以太网连接和网络应用评估的 ESP32 开发板。板载能力包括：Ethernet PHY、RJ45、microSD、USB-UART。

板载能力
--------

* Ethernet PHY、RJ45、microSD、USB-UART

硬件用户指南
------------

完整硬件说明见 `ESP32-Ethernet-Kit <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32/esp32-ethernet-kit/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_ethernet_kit``。
