ESP-VoCat v1.2
==============

:link_to_translation:`en:[English]`

ESP-VoCat 的 V1.2 硬件版本。板载能力包括：圆形触摸屏、双麦克风、音频编解码、microSD、状态 LED、GPIO Boot 按键。

板载能力
--------

* 圆形触摸屏、双麦克风、音频编解码、microSD、状态 LED、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP-VoCat V1.2 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp-vocat/user_guide_v1.2.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp_vocat_1_2``。
