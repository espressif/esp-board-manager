ESP-VoCat v1.0
==============

:link_to_translation:`en:[English]`

面向语音交互的 ESP32-S3 开发板。板载能力包括：圆形触摸屏、双麦克风、音频编解码、microSD、GPIO Boot 按键。

板载能力
--------

* 圆形触摸屏、双麦克风、音频编解码、microSD、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP-VoCat V1.0 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp-vocat/user_guide_v1.0.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp_vocat_1_0``。
