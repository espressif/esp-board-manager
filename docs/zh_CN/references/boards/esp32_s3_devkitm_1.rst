ESP32-S3-DevKitM-1
==================

:link_to_translation:`en:[English]`

基于 ESP32-S3-MINI-1 模组的通用开发板。板载能力包括：ESP32-S3-MINI-1、USB、GPIO 引脚。

板载能力
--------

* ESP32-S3-MINI-1、USB、GPIO 引脚

硬件用户指南
------------

完整硬件说明见 `ESP32-S3-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp32-s3-devkitm-1/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_s3_devkitm_1``。
