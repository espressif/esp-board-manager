ESP-DualKey
===========

:link_to_translation:`en:[English]`

用于按键和人机交互功能验证的 ESP32 开发板。板载能力包括：双按键输入、USB、GPIO 扩展。

板载能力
--------

* 双按键输入、USB、GPIO 扩展

硬件用户指南
------------

完整硬件说明见 `ESP-DualKey <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp-dualkey/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp_dualkey``。
