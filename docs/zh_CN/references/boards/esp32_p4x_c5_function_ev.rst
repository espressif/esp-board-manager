ESP32-P4X-C5-Function-EV-Board
==============================

:link_to_translation:`en:[English]`

用于多芯片协同多媒体应用评估的开发板。板载能力包括：ESP32-P4 与 ESP32-C5、显示、触摸、音频、摄像头、GPIO Boot 按键。

板载能力
--------

* ESP32-P4 与 ESP32-C5、显示、触摸、音频、摄像头、GPIO Boot 按键

硬件用户指南
------------

完整硬件说明见 `ESP32-P4X-C5-Function-EV-Board <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32p4/esp32-p4x-c5-function-ev-board/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_p4x_c5_function_ev``。
