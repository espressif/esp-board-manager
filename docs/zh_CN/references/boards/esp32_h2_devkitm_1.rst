ESP32-H2-DevKitM-1
==================

:link_to_translation:`en:[English]`

面向 Thread 和 Zigbee 应用的低功耗开发板。板载能力包括：ESP32-H2-MINI-1、802.15.4、USB。

板载能力
--------

* ESP32-H2-MINI-1、802.15.4、USB

硬件用户指南
------------

完整硬件说明见 `ESP32-H2-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32h2/esp32-h2-devkitm-1/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_h2_devkitm_1``。
