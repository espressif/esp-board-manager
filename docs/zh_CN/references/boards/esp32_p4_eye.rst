ESP32-P4-EYE
============

:link_to_translation:`en:[English]`

面向视觉应用的 ESP32-P4 开发板。板载能力包括：CSI 摄像头、ST7789 LCD、microSD、内部 ADC、GPIO 按键、GPIO Boot 按键、旋钮。

板载能力
--------

* CSI 摄像头、ST7789 LCD、microSD、内部 ADC、GPIO 按键、GPIO Boot 按键、旋钮

硬件用户指南
------------

完整硬件说明见 `ESP32-P4-EYE <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32p4/esp32-p4-eye/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_boards/esp32_p4_eye``。
