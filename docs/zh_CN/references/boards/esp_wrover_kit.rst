ESP-WROVER-KIT v3 入门指南
=======================================

:link_to_translation:`en:[English]`

基于 ESP32 的通用开发板。板载能力包括：ST7789 LCD、microSD、按键、蓝色 LED、SPIFFS。

板载能力
--------

* ST7789 LCD、microSD、按键、蓝色 LED、SPIFFS

硬件用户指南
------------

完整硬件说明见 `ESP-WROVER-KIT <https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32/esp-wrover-kit/index.html>`__。

BMGR 配置
---------

板级配置目录为 ``esp_friends_boards/esp_wrover_kit``。
