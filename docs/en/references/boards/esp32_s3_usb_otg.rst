ESP32-S3-USB-OTG
================

:link_to_translation:`zh_CN:[中文]`

ESP32-S3 board for USB host and device development. Onboard capabilities include: USB OTG, USB Type-C, microSD, buttons.

Onboard Capabilities
--------------------

* USB OTG, USB Type-C, microSD, buttons

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-S3-USB-OTG <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-usb-otg/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_s3_usb_otg``.
