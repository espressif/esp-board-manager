ESP-VoCat v1.2
==============

:link_to_translation:`zh_CN:[中文]`

V1.2 hardware revision of ESP-VoCat. Onboard capabilities include: Round touch display, dual microphones, audio codec, microSD, status LED, GPIO boot button.

Onboard Capabilities
--------------------

* Round touch display, dual microphones, audio codec, microSD, status LED, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP-VoCat V1.2 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp-vocat/user_guide_v1.2.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp_vocat_1_2``.
