ESP32-PICO-DevKitM-2
====================

:link_to_translation:`zh_CN:[中文]`

Compact board based on ESP32-PICO modules. Onboard capabilities include: ESP32-PICO-MINI-02, USB-UART, GPIO headers.

Onboard Capabilities
--------------------

* ESP32-PICO-MINI-02, USB-UART, GPIO headers

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-PICO-DevKitM-2 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-pico-devkitm-2/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_pico_devkitm_2``.
