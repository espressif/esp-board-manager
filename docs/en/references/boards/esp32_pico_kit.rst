ESP32-PICO-KIT v4/v4.1
======================

:link_to_translation:`zh_CN:[中文]`

Development board based on ESP32-PICO-D4. Onboard capabilities include: ESP32-PICO-D4, USB-UART, GPIO headers.

Onboard Capabilities
--------------------

* ESP32-PICO-D4, USB-UART, GPIO headers

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-PICO-KIT <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-pico-kit/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_pico_kit``.
