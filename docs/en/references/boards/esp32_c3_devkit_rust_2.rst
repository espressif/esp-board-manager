ESP32-C3-DevKit-RUST-2
======================

:link_to_translation:`zh_CN:[中文]`

Updated ESP32-C3 Rust development board. Onboard capabilities include: ICM-42670-P IMU, SHTC3, WS2812, button, USB.

Onboard Capabilities
--------------------

* ICM-42670-P IMU, SHTC3, WS2812, button, USB

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-C3-DevKit-RUST-2 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c3/esp32-c3-devkit-rust-2/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_c3_devkit_rust_2``.
