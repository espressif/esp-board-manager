ESP32-C3-DevKitC-02
===================

:link_to_translation:`zh_CN:[中文]`

General-purpose ESP32-C3 development board. Onboard capabilities include: ESP32-C3-WROOM-02, USB, GPIO headers.

Onboard Capabilities
--------------------

* ESP32-C3-WROOM-02, USB, GPIO headers

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-C3-DevKitC-02 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c3/esp32-c3-devkitc-02/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_c3_devkitc_02``.
