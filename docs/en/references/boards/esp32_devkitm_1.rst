ESP32-DevKitM-1
===============

:link_to_translation:`zh_CN:[中文]`

General-purpose board based on ESP32-WROOM-32. Onboard capabilities include: ESP32-WROOM-32, USB-UART, GPIO headers.

Onboard Capabilities
--------------------

* ESP32-WROOM-32, USB-UART, GPIO headers

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitm-1/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_devkitm_1``.
