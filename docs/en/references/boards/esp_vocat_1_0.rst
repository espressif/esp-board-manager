ESP-VoCat v1.0
==============

:link_to_translation:`zh_CN:[中文]`

ESP32-S3 board for voice interaction. Onboard capabilities include: Round touch display, dual microphones, audio codec, microSD, GPIO boot button.

Onboard Capabilities
--------------------

* Round touch display, dual microphones, audio codec, microSD, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP-VoCat V1.0 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp-vocat/user_guide_v1.0.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp_vocat_1_0``.
