ESP32-LCDKit
============

:link_to_translation:`zh_CN:[中文]`

ESP32 board for compact GUI and HMI applications. Onboard capabilities include: SPI LCD, touch, knob, audio, infrared, WS2812.

Onboard Capabilities
--------------------

* SPI LCD, touch, knob, audio, infrared, WS2812

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-LCDKit <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-lcdkit/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_lcdkit``.
