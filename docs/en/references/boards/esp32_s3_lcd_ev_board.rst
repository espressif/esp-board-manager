ESP32-S3-LCD-EV-Board v1.5
==========================

:link_to_translation:`zh_CN:[中文]`

Board for ESP32-S3 display evaluation. Onboard capabilities include: GC9503 RGB LCD, FT5x06, ES8311/ES7210, GPIO boot button.

Onboard Capabilities
--------------------

* GC9503 RGB LCD, FT5x06, ES8311/ES7210, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-S3-LCD-EV-Board <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-lcd-ev-board/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_s3_lcd_ev_board``.
