ESP32-C6-DevKitM-1
==================

:link_to_translation:`zh_CN:[中文]`

Development board based on ESP32-C6-MINI-1. Onboard capabilities include: ESP32-C6-MINI-1, Wi-Fi 6, 802.15.4, USB.

Onboard Capabilities
--------------------

* ESP32-C6-MINI-1, Wi-Fi 6, 802.15.4, USB

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-C6-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c6/esp32-c6-devkitm-1/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_c6_devkitm_1``.
