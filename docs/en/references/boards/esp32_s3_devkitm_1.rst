ESP32-S3-DevKitM-1
==================

:link_to_translation:`zh_CN:[中文]`

General-purpose board based on ESP32-S3-MINI-1. Onboard capabilities include: ESP32-S3-MINI-1, USB, GPIO headers.

Onboard Capabilities
--------------------

* ESP32-S3-MINI-1, USB, GPIO headers

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-S3-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitm-1/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_s3_devkitm_1``.
