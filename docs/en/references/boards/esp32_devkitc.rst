ESP32-DevKitC V4
================

:link_to_translation:`zh_CN:[中文]`

General-purpose ESP32-WROOM-32 development board. Onboard capabilities include: ESP32-WROOM-32, USB-UART, GPIO headers.

Onboard Capabilities
--------------------

* ESP32-WROOM-32, USB-UART, GPIO headers

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-DevKitC <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_devkitc``.
