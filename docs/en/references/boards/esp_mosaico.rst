ESP-Mosaico V1.0
================

:link_to_translation:`zh_CN:[中文]`

Expandable ESP32-S31 smart-interaction development kit. Onboard capabilities include: 480x480 QSPI touch display, ES8311, BMI270, BMM150, SPI NAND, USB OTG, GPIO boot button.

Onboard Capabilities
--------------------

* 480x480 QSPI touch display, ES8311, BMI270, BMM150, SPI NAND, USB OTG, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP-Mosaico <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s31/esp-mosaico/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp_mosaico``.
