ESP32-MeshKit-Sense
===================

:link_to_translation:`zh_CN:[中文]`

Development kit for Wi-Fi Mesh and sensing applications. Onboard capabilities include: Environmental sensors, LCD, touch, Wi-Fi/BLE, GPIO boot button.

Onboard Capabilities
--------------------

* Environmental sensors, LCD, touch, Wi-Fi/BLE, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-MeshKit-Sense <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-meshkit-sensor/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_meshkit_sense``.
