ESP32-P4-EYE
============

:link_to_translation:`zh_CN:[中文]`

ESP32-P4 board for vision applications. Onboard capabilities include: CSI camera, ST7789 LCD, microSD, internal ADC, GPIO buttons, GPIO boot button, knob.

Onboard Capabilities
--------------------

* CSI camera, ST7789 LCD, microSD, internal ADC, GPIO buttons, GPIO boot button, knob

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-P4-EYE <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32p4/esp32-p4-eye/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_p4_eye``.
