ESP32-Ethernet-Kit v1.2
=======================

:link_to_translation:`zh_CN:[中文]`

ESP32 board for Ethernet and network application evaluation. Onboard capabilities include: Ethernet PHY, RJ45, microSD, USB-UART.

Onboard Capabilities
--------------------

* Ethernet PHY, RJ45, microSD, USB-UART

The complete hardware guide is available at `ESP32-Ethernet-Kit <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-ethernet-kit/index.html>`__.

The board definition is in ``esp_boards/esp32_ethernet_kit``.
