ESP32-P4X-C5-Function-EV-Board
==============================

:link_to_translation:`zh_CN:[中文]`

Board for multi-chip multimedia application evaluation. Onboard capabilities include: ESP32-P4 and ESP32-C5, display, touch, audio, camera, GPIO boot button.

Onboard Capabilities
--------------------

* ESP32-P4 and ESP32-C5, display, touch, audio, camera, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-P4X-C5-Function-EV-Board <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32p4/esp32-p4x-c5-function-ev-board/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_p4x_c5_function_ev``.
