ESP32-C3-LCDkit
===============

:link_to_translation:`zh_CN:[中文]`

ESP32-C3 board for display applications. Onboard capabilities include: GC9A01 SPI LCD, PDM speaker, knob, WS2812, SPIFFS.

Onboard Capabilities
--------------------

* GC9A01 SPI LCD, PDM speaker, knob, WS2812, SPIFFS

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-C3-LCDkit <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c3/esp32-c3-lcdkit/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_c3_lcdkit``.
