ESP32-H2-DevKitM-1
==================

:link_to_translation:`zh_CN:[中文]`

Low-power board for Thread and Zigbee applications. Onboard capabilities include: ESP32-H2-MINI-1, 802.15.4, USB.

Onboard Capabilities
--------------------

* ESP32-H2-MINI-1, 802.15.4, USB

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-H2-DevKitM-1 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32h2/esp32-h2-devkitm-1/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_h2_devkitm_1``.
