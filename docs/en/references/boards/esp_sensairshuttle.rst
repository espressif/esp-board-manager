ESP-SensairShuttle v1.0
=======================

:link_to_translation:`zh_CN:[中文]`

ESP32-C5 board for motion sensing and large-model HMI. Onboard capabilities include: BMI270, audio input/output, LCD, touch, WS2812, GPIO boot button.

Onboard Capabilities
--------------------

* BMI270, audio input/output, LCD, touch, WS2812, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP-SensairShuttle <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c5/esp-sensairshuttle/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp_sensairshuttle``.
