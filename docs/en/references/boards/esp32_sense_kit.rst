ESP32-Sense-Kit
===============

:link_to_translation:`zh_CN:[中文]`

Kit for ESP32 touch and audio evaluation. Onboard capabilities include: Touch sensing, microphone, speaker, LCD.

Onboard Capabilities
--------------------

* Touch sensing, microphone, speaker, LCD

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-Sense-Kit <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-sense-kit/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_sense_kit``.
