ESP32-S31-Function-CoreBoard-1
==============================

:link_to_translation:`zh_CN:[中文]`

Board for connected AIoT prototyping. Onboard capabilities include: ES8311, microphone, speaker interface, WS2812, GPIO boot button.

Onboard Capabilities
--------------------

* ES8311, microphone, speaker interface, WS2812, GPIO boot button

Hardware User Guide
-------------------

The complete hardware guide is available at `ESP32-S31-Function-CoreBoard-1 <https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s31/esp32-s31-function-coreboard-1/index.html>`__.

BMGR Configuration
------------------

The board definition is in ``esp_boards/esp32_s31_function_coreboard_1``. This chip requires ESP-IDF ``v6.1`` or later.
