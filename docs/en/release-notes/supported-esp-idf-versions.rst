Supported ESP-IDF Versions
===========================

:link_to_translation:`zh_CN:[中文]`

ESP Board Manager currently supports the following ESP-IDF versions:

- ESP-IDF ``release/v5.4``, minimum ``v5.4.4``.
- ESP-IDF ``release/v5.5``, minimum ``v5.5.3``.
- ESP-IDF ``release/v6.0`` and later.

The ESP32-S31 target is available from ESP-IDF ``v6.1``. ``release/v6.0`` and earlier branches do not include this chip.
